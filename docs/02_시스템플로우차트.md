## 1. 전체 시퀀스 다이어그램

```mermaid
sequenceDiagram
    autonumber
    actor Admin as 관리자/사용자
    participant API as Backend API (FastAPI)
    participant BG as BackgroundTasks + AiJob
    participant DB as PostgreSQL + pgvector
    participant S3 as Object Storage
    participant OCR as 문서처리 (PyMuPDF · RapidOCR)
    participant RAG as Hybrid RAG (BGE-M3 · BM25)
    participant LG as LangGraph Pipeline
    participant LLM as OpenAI (gpt-4o-mini)
    participant LS as LangSmith

    Note over Admin, LS: [1] 인증
    Admin->>API: 로그인 요청
    API->>DB: 계정 및 승인 상태 확인
    DB-->>API: 정보 반환
    API-->>Admin: JWT 토큰 발급 (Bearer)

    Note over Admin, LS: [2] 지원자 등록 및 문서 업로드
    Admin->>API: 지원자 등록 (이름 · 직무 · 기본정보)
    API->>DB: candidate 저장
    Admin->>API: 이력서 / 포트폴리오 업로드
    API->>S3: 파일 저장
    API->>DB: document 생성 (extract_status=PENDING)
    API-->>Admin: 등록 성공

    Note over API, OCR: [3] 비동기 텍스트 추출
    API->>BG: BackgroundTask 등록
    BG->>OCR: PDF / 이미지 텍스트 추출 요청
    OCR-->>BG: 추출 텍스트 반환
    BG->>RAG: BGE-M3 임베딩 요청
    RAG-->>BG: 벡터 반환
    BG->>DB: extracted_text + 벡터 저장 (status=READY)

    Note over Admin, LS: [4] 세션 생성 및 질문 생성 요청
    Admin->>API: 직무별 지원자 그룹화 + 세션 생성
    API->>DB: interview_session 저장
    API->>BG: AiJob 생성 (status=PENDING)
    BG->>DB: ai_job 저장

    Note over BG, LS: [5] LangGraph 멀티에이전트 실행
    BG->>LG: 세션 + 지원자 정보 전달
    BG->>DB: ai_job 상태 업데이트 (status=RUNNING)

    LG->>LLM: questioner — 핵심 질문 생성
    LLM-->>LG: 질문 반환

    LG->>LLM: predictor — 예상 답변 시뮬레이션
    LLM-->>LG: 예상 답변 반환

    LG->>LLM: driller — 심화 꼬리질문 생성
    LLM-->>LG: 꼬리질문 반환

    LG->>LLM: reviewer — 루브릭 기준 품질 검토
    LLM-->>LG: 검토 결과 반환

    LG->>LS: 노드별 trace 기록 (토큰 · 레이턴시 · 비용)

    Note over BG, DB: [6] 결과 저장
    LG-->>BG: 최종 결과 (JSON)
    BG->>DB: interview_question_item 저장 (질문 · 예상답변 · 평가가이드)
    BG->>DB: llm_call_log 저장 (노드별 토큰 · 비용 · 실행시간)
    BG->>DB: ai_job 상태 업데이트 (status=COMPLETED)

    Note over Admin, LS: [7] 결과 조회 및 확인
    Admin->>API: 결과 조회 요청
    API->>DB: 질문 · 로그 조회
    DB-->>API: 데이터 반환
    API-->>Admin: 질문 · 예상답변 · 평가가이드 반환
    Admin->>API: LLM 사용량 대시보드 조회 (LangSmith 연동)
    API->>LS: 토큰 · 비용 · 레이턴시 조회 (API)
    LS-->>API: 사용량 데이터 반환
    API-->>Admin: 대시보드 렌더링
```

## 2. 채용공고 컴플라이언스 검토 흐름

```mermaid
sequenceDiagram
    autonumber
    actor Admin as 관리자/사용자
    participant API as Backend API (FastAPI)
    participant RULE as Rule 탐지 (RISK_PATTERNS)
    participant RAG as Hybrid RAG
    participant VEC as pgvector (BGE-M3)
    participant BM25 as BM25 (PostgreSQL FTS)
    participant RR as BGE-reranker-v2-m3
    participant LLM as OpenAI (gpt-4o-mini)
    participant DB as PostgreSQL

    Note over Admin, DB: [1] 채용공고 입력
    Admin->>API: 채용공고 텍스트 입력
    API-->>Admin: 검토 시작

    Note over API, RULE: [2] 1단계 — Rule 기반 즉시 탐지
    API->>RULE: 정규식 패턴 매칭
    RULE-->>API: 위반 항목 플래그 (키·체중·혼인여부 등)

    Note over API, RR: [3] 2단계 — Hybrid RAG 법령 검색
    API->>VEC: BGE-M3 의미 기반 검색
    VEC-->>API: 유사 법령 조항 반환
    API->>BM25: 키워드 기반 검색
    BM25-->>API: 키워드 매칭 조항 반환
    API->>RR: 두 결과 통합 후 reranking
    RR-->>API: 최종 관련 법령 조항

    Note over API, LLM: [4] 리포트 생성
    API->>LLM: Rule 탐지 결과 + 법령 조항 전달
    LLM-->>API: 위반 항목 · 근거 조항 · 수정 권고 (JSON)
    API->>DB: 검토 결과 저장

    Note over Admin, DB: [5] 결과 반환
    API-->>Admin: 컴플라이언스 리포트\n(위반 항목 · 관련 법령 · 수정 권고)
```
