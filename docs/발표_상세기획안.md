### Slide 5 — 문제정의: 면접 질문 생성

**제목:** 면접 준비, 왜 AI가 필요한가

**핵심 근거 이미지:** 사람인 설문조사 인포그래픽 삽입
> 출처: 사람인, 인사담당자 377명 설문조사

**핵심 수치 강조 (3개 카드):**
```
인사담당자 83%      1위 어려움        우리 에이전트가
"면접이 어렵다"     지원자 포장·과장   해결합니다
                   분별 (54%)
```

**내용 구성:**

| 문제 | 근거 |
|------|------|
| 인사담당자 10명 중 8명이 면접에서 어려움을 느낀다 | 사람인 설문조사, 인사담당자 377명 |
| 가장 큰 어려움 1위: 지원자의 포장·과장 분별 (54%) | → 우리 에이전트는 9가지 유형 분류 + 꼬리질문으로 검증 |
| 2위 역량 변별력 부재 (32.6%), 3위 거짓말 판별 (31.6%) | → driller 노드가 허점 공략 심화 질문 자동 생성 |

**발표 키워드:**
- "인사담당자 83%가 면접에서 어려움을 느낀다고 답했습니다"
- "1위 이유가 '지원자의 포장과 과장을 분별하기 어렵다'입니다"
- "저희 에이전트는 이 문제를 직접 겨냥합니다"
- "지원자 유형을 먼저 분류하고, 허점을 파고드는 꼬리질문을 자동으로 만들어냅니다"

### Slide 10 — LangGraph 멀티에이전트 파이프라인

**제목:** 4개 에이전트가 협업해서 질문을 만든다

**노드 흐름도:**
```
questioner  →  predictor  →  driller  →  reviewer
(질문 생성)    (예상답변)    (꼬리질문)   (품질 검토)
                                            ↓
                                      기준 미달 시 재생성 (루프)
```

|------|------|

| driller | 허점 공략 심화·꼬리 질문 |
| reviewer | 루브릭 기준으로 전체 품질 검토 |

**발표 키워드:**
- "4개의 에이전트가 순서대로 협업합니다"
